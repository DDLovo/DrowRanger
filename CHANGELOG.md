# Changelog

## 0.2.9

- Refined classic armor-piercing arrows with a wider blue-white envelope and a visible arrow silhouette.
- Reworked Arcana armor-piercing arrows with a red core and black angular fragments, based on Dota reference screenshots.
- Added subtle, tightly wound spiral trails to classic Winter Strike and richer layered triangle trails to Arcana Winter Strike, with lingering trails after impact.
- Changed the package website link to the Thunderstore mod page.
- No changes to damage, proc coefficients, projectile speed, or hit detection.

## 0.2.8

- Updated the overview layout and feedback links.
- Cropped both character selection screenshots to remove the right-side options and Ready button.
- No gameplay changes.

## 0.2.7

- Added optional LookingGlass integration for proc coefficients, empowered-arrow details, and per-hit explanations. No changes to actual proc values.
- Moved all settings to a separate `BepInEx/config/DrowRanger.cfg`, created on first launch. Previous DotaHero config files are no longer used.
- Removed installation instructions from the overview and added three in-game screenshots, including a cropped combat image.
- Added a short AI-use disclosure.

## 0.2.6

- Renamed the package from DotaHero to **DrowRanger** and the plugin display name to **Drow Ranger**.
- Added an English overview, skill and relic tables, installation instructions, and credits.
- Kept the existing plugin ID and configuration filename for compatibility.
- No gameplay, balance, animation, or audio changes from 0.2.5.
- **Migration:** uninstall the old DotaHero package before importing DrowRanger. Keep `local.dotahero.cfg` to preserve settings.

## 0.2.5

- Added original Dota selection entrances for both skins, transitioning into their display idle animations.
- Removed Arcana dialogue while retaining weapon, skill, reload, and death sound effects.

## 0.2.4

- Synchronized English descriptions with the revised Chinese text.
- Added 50% faster arrow projectiles to Hurricane Pike, including assisted aiming.
- Added transparent status icons and refined survivor portrait outlines.

## 0.2.3

- Increased Winter Strike's arrow size and trail visibility for both skins.

## 0.2.2

- Refined airborne cloth and hair motion.
- Reworked Gust, arrow trails, armor-piercing effects, and ice explosions using Dota source effects as references.
